# job-platform-analysis

채용플랫폼 지원 행동 분석
Python / pandas / Matplotlib / SciPy | Team Project
채용플랫폼의 지원 및 탐색 행동 데이터를 분석해 단기간에 지원이 집중되는 사용자를 식별하는 대량성 기준을 설정하고, G0와 G3 사용자 그룹의 행동 차이를 비교한 프로젝트입니다.
이 저장소에는 팀 프로젝트에서 제가 담당한 대량성 기준 설계와 사용자 그룹 비교 분석을 정리했습니다.
My Role
- 지원 시각을 한국 시간으로 변환하고 사용자별 지원 이력 전처리
- 7일, 14일, 21일, 30일 이동 구간의 최대 지원 건수 계산
- IQR, 백분위수, 연도별 분포를 비교해 대량성 판별 기준 설정
- 지원, 공고, 북마크, 로그 데이터를 결합해 사용자별 행동 지표 생성
- G0와 G3의 지원 및 탐색 행동 시각화와 통계 검정
- 2022년과 2023년을 나누어 그룹 간 차이의 일관성 확인
Data
- 분석 기간: 2022년 1월 1일 ~ 2023년 12월 31일, 한국 시간 기준
- 전체 지원 데이터: 92,526건
- 전체 지원 사용자: 10,287명
- 활용 데이터: 지원 이력, 공고 정보, 북마크, 서비스 요청 로그, 팀에서 정의한 사용자 그룹
1. 대량성 기준 설정
사용자별로 각 지원 시점 직전의 연속 7일, 14일, 21일, 30일 동안 발생한 지원 건수를 계산하고, 구간별 최대값을 비교했습니다.
단기간에 지원이 몰리는 행동을 포착하기 위해 연속 7일 내 최대 지원 건수가 14건 이상인 사용자를 대량성 신호가 있는 사용자로 정의했습니다. 여기서 지원 건수는 지원 이벤트 수이며, 서로 다른 공고 수와는 구분됩니다.
기준 선정 근거
- 7일 최대 지원 건수의 Q1은 1건, Q3는 4건으로 IQR은 3건이었습니다.
- Q3 + 3 × IQR = 13을 초과하는 정수 기준인 14건 이상을 적용했습니다.
- 연도별로 계산해도 같은 기준이 도출되었으며, 해당 사용자 비율도 유사했습니다.
분석 범위	7일 대량성 기준	해당 사용자	해당 비율
전체 기간	14건 이상	545명	5.30%
2022년	14건 이상	302명	5.17%
2023년	14건 이상	293명	5.12%


연도별 비율은 각 연도에 지원한 사용자를 기준으로 계산했습니다. 두 연도에 모두 지원한 사용자가 있으므로 연도별 인원을 더한 값은 전체 기간의 인원과 다릅니다.
최종 결과는 사용자별 volume_score로 저장했습니다. 기준에 해당하면 1, 해당하지 않으면 0을 부여합니다.
2. G0와 G3 행동 비교
팀에서 정의한 사용자 그룹 중 **G0(신호없음)**와 **G3(고중첩신호)**를 비교했습니다. 그룹 정보는 별도 입력 파일인 user_group.csv를 사용했습니다.
사용자별 지원 건수, 활동일당 지원 건수, 지원 간격, 지원 전 북마크 비율, 야간 및 주말 지원 비율 등을 계산했습니다. 로그는 정상 응답 요청을 대상으로 중복을 제거하고, 공고 상세 조회와 지원 내역 조회 등 요청 유형별 지표를 생성했습니다.
주요 결과
지표	G0	G3
비교 사용자 수	8,362명	104명
사용자별 지원 건수 중앙값	2건	47.5건
활동일당 지원 건수 평균	1.47건	9.84건
사용자별 전체 로그 요청 수 평균	1,109.13건	4,128.67건
지원 1건당 공고 상세 조회 요청 수 평균	26.95건	5.14건


활동일당 지원 건수와 지원 1건당 상세 조회 요청 수는 각 사용자의 비율을 먼저 계산한 뒤 평균한 값입니다. 상세 조회 요청은 로그에 기록된 요청 수로, 실제 열람 시간이나 내용을 읽은 정도를 의미하지 않습니다.
G3는 지원 건수와 전체 로그 요청 수가 높았지만, 지원 1건당 공고 상세 조회 요청 수는 낮았습니다. 이를 통해 그룹별 지원 규모뿐 아니라 지원과 탐색 활동의 관계를 함께 살펴볼 필요가 있음을 확인했습니다.
야간 및 주말 행동 비율 등 주요 지표에는 Mann–Whitney U 검정을 적용하고, 지원 지표와 로그 지표를 각각 묶어 Bonferroni 보정을 수행했습니다. 연도별 비교도 함께 진행해 전체 기간의 차이가 각 연도에서도 나타나는지 확인했습니다.
